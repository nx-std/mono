# Meta Documentation

This directory contains authoring guides and format specifications for different kinds of project documentation:

- **[feat.md](feat.md)** — Format specification for feature documentation in `docs/feat/`
- **[code.md](code.md)** — Format specification for the code rules in `docs/code/`
- **[code-principle.md](code-principle.md)** — Structure template for principle rule documents
- **[code-pattern.md](code-pattern.md)** — Structure template for pattern rule documents
- **[code-rust.md](code-rust.md)** — Structure template for Rust convention rule documents
